📚 Online Book Store — MySQL Project

📌 Project Overview
The Online Book Store project is a SQL-based data analysis project developed using MySQL. It focuses on managing bookstore data and analyzing customer orders, book sales, revenue, and purchasing patterns.

🎯 Project Objectives
• Manage and analyze bookstore data using MySQL.
• Identify top-selling books.
• Analyze customer purchasing behavior.
• Calculate total sales and revenue.
• Practice SQL queries for business analysis.

🛠️ Tools & Technologies
• MySQL
• SQL
• GitHub

🗂️ Project Structure
• `online store backup.sql` — Contains the database backup and SQL queries.

📊 SQL Concepts Used
• `SELECT` and `WHERE` statements
• `ORDER BY`
• `GROUP BY` and `HAVING`
• Aggregate functions: `SUM()`, `AVG()`, `COUNT()`
• SQL `JOINS`
• Subqueries
• `CASE` statements
• Window functions (if implemented)

🔍 Key Business Questions
• What are the total sales and revenue?
• Which books sell the most?
• Who are the top customers by spending?
• Which books generate the highest revenue?
• How many orders are placed by customers?
• What is the average order value?

🚀 How to Run the Project
① Install MySQL Server and MySQL Workbench.
② Clone or download this repository.
③ Open MySQL Workbench.
④ Open the `online store backup.sql` file.
⑤ Execute the SQL script to create the database and tables and run the queries.
