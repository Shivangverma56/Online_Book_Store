📚 Online Book Store — MySQL Project

📌 Project Overview

The Online Book Store is a SQL-based data analysis project developed using MySQL. It focuses on managing book store data and analyzing customer orders, book sales, revenue, and purchasing patterns.

🎯 Project Objectives

- Manage and analyze book store data using MySQL.
- Identify top-selling books.
- Analyze customer purchasing behavior.
- Calculate total sales and revenue.
- Practice SQL queries for business analysis.

🛠️ Tools & Technologies

- MySQL
- SQL
- GitHub

📂 Project Structure

- "online store backup.sql" — Database backup and SQL queries.

📊 SQL Concepts Used

- SELECT and WHERE
- ORDER BY
- GROUP BY and HAVING
- Aggregate Functions (SUM, AVG, COUNT)
- JOINs
- Subqueries
- CASE Statements
- Window Functions (if implemented)

🔍 Key Business Questions

- What are the total sales and revenue?
- Which books sell the most?
- Who are the top customers by spending?
- Which books generate the highest revenue?
- How many orders are placed by customers?
- What is the average order value?

🚀 How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Download or clone this repository.
3. Open the ".sql" file in MySQL Workbench.
4. Execute the SQL script to create the database and tables.
5. Run the queries to analyze the data.
